# SAFE conventions acceptance

This release stacks on comparison PR #5. It adds a guide-based equity-financing reference model; option-pool top-ups remain a separate feature. Use hypothetical anonymous scenarios.

1. Load a schema-v2 legacy draft. Its original bytes must be retained before autosave migrates metadata to schema v3. The selector reads **Legacy simplified pre-conversion**, model version remains `pre-conversion-v2`, and every financial result is unchanged.
2. For one founder with 10M shares, reserve zero, a $1M SAFE with $10M cap, and a $20M pre-money / $5M cash round, legacy results remain price $2, SAFE 1M shares, new investor 2.5M shares, founder ownership 74.074%, and capitalization at round price $27M (quoted pre+cash $25M).
3. Duplicate that case, choose **Post-money SAFE reference (YC guide)**, then explicitly select **Post-money cap only**. No financial input is cleared automatically. New results are price $1.80, founder 72%, SAFE 8%, new investor 20%, and capitalization $25M. Reference shares are fractional. Comparison shows convention, calculation-version and form differences; it must never claim these inputs are identical.
4. Reload. Case identity, convention, form, full input precision, and calculation version survive. The legacy baseline is unchanged. Switching back to legacy is an explicit convention choice; it restores generic legacy form semantics without changing monetary inputs.
5. Check cap-only, discount-only, and custom/historical combined term constraints. Cap-only requires a positive cap and zero discount; discount-only requires zero cap. A 20% discount off price corresponds to an 80% contract Discount Rate. Combined terms are labeled custom/historical throughout, not as a current YC standard form.
6. Reference fixture matrix and custom cap/discount crossover are in [safe-conventions-design.md](safe-conventions-design.md). Reordering multiple SAFEs preserves holdings by identity. Impossible aggregate conversion claims of 100% or more, nonfinite/overflow/underflow values, and unsupported form or model tags block results, save, and export.
7. A nonzero existing reserve must be included before financing in post-money mode. Grants transfer that reserve; they do not create a financing pool increase. The new convention rejects separate promised-option adjustments, financing top-up metadata, MFN, pro-rata participation, legacy/pre-money mixtures, and later SAFE issuance timing.
8. All listed post-money SAFEs are outstanding before the first positive-cash priced financing and convert there. Zero-cash events do not trigger conversion. An old explicit target that skips an earlier financing becomes an error when adopting the new convention. Removing an explicitly selected round preserves its missing reference until reassigned. An unspecified target follows the first financing after reordering.
9. Inspect calculation details and the workbook. The share bridge starts with shares **before** conversion; the pricing denominator includes all conversions. Converted marked value is already inside the post-money model's financing pre-money and is not added twice. Cap-table/chart share formats retain six displayed decimals; actual issuance rounding is expressly unsupported. Legacy export retains whole-share formatting and its existing bridge.
10. Complete adoption, correction, comparison, reload, cap-table inspection, and XLSX download on mobile and desktop. Inputs remain labeled; form errors are linked; dropdowns and tables stay inside the viewport at 320/390/768/1440px.

Scope: US reference equity-financing mechanics from the official YC guide; no complete contractual/legal or exit modeling. The exact DOCX forms could not be inspected because the container proxy rejected their public download. Source provenance and that limitation must remain visible in the review materials. An authenticated HTTP 200 response or Vercel READY state is not deployed-browser verification. Parent browser testing should use the exact preview commit before claiming that result. Keep deployment protection enabled; do not merge or promote production.
